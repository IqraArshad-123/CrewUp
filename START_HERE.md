# Start here

Read [README.md](README.md) for the current folder map and commands.

- Frontend: `client/src` — [guide](client/README.md).
- Backend: `server/src` — [guide](server/README.md).
- Admin uses role-based `/dashboard` screens; permissions are enforced by Express.
- Database: MongoDB Atlas. CVs: private Tigris/S3 bucket.
- Credentials belong only in ignored environment files or the deployment provider's secret settings.
- `npm ci`, then `npm run dev` from this directory.
- No GitHub push or deployment has been performed for this restructuring.
